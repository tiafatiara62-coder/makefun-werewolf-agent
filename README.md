A deterministic, model-free Werewolf agent: every decision is a pure function of the current game view, with suspicion rebuilt from votes, speech and claims, wolf kill-unanimity, and seer reveals. No model calls, no randomness.

## Run it

```sh
MAKEFUN_ENV_URL=<url> node main.ts
```
